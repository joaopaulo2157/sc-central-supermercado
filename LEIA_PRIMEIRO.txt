CORREÇÃO DO PUBLICADOR SUPABASE

O erro:
  cannot pull with rebase: You have unstaged changes

acontecia porque havia alterações locais rastreadas que o script anterior
não adicionava ao commit.

ESTE SCRIPT:
- executa npm run check;
- verifica se .env real está sendo rastreado e bloqueia por segurança;
- adiciona todas as modificações de arquivos já rastreados (git add -u);
- adiciona somente os novos arquivos conhecidos da integração Supabase;
- NÃO adiciona arquivos aleatórios não rastreados;
- cria commit;
- executa git pull --rebase origin main;
- executa git push origin main;
- nunca usa force push;
- nunca apaga alterações locais.

COMO USAR:
1. Copie CONECTAR_SUPABASE.bat para a raiz do repositório SC Central.
2. Substitua o arquivo anterior.
3. Execute-o novamente.
