SUPERMERCADO SC CENTRAL - V3

A V3 foi construída em cima da V2 sem remover as funcionalidades anteriores.
A estrutura continua em HTML + CSS + JavaScript puro e agora inclui um painel administrativo funcional para demonstração.

ARQUIVOS PRINCIPAIS
- index.html             Loja / catálogo
- style.css              CSS acumulado V1 + V2
- script.js              JavaScript acumulado V1 + V2
- v3.css                 Evoluções visuais da V3
- v3.js                  Evoluções funcionais da V3
- v3-data.js             Dados padrão compartilhados
- admin.html             Painel administrativo V3
- admin.css              Estilos do painel
- admin.js               Lógica do painel
- assets/logo-sc-central.png

COMO USAR
1. Abra index.html para acessar a loja.
2. Abra admin.html para acessar o painel administrativo.
3. No painel, vá em Configurações e informe o WhatsApp real da loja.
4. Cadastre/edite produtos, preços, estoque, fotos, banners, cupons e regiões.
5. Atualize a aba da loja para visualizar as alterações.

IMPORTANTE SOBRE ESTA VERSÃO
A V3 funciona sem backend utilizando localStorage. Isto permite demonstrar praticamente todo o fluxo ao cliente final diretamente no navegador.

Como os dados estão no navegador:
- outro computador não verá os mesmos cadastros;
- limpar os dados do navegador apaga as alterações locais;
- o painel ainda não possui autenticação real de servidor;
- não há sincronização entre vários atendentes/dispositivos.

A próxima evolução natural é manter toda esta interface e trocar o armazenamento local por API + banco de dados, adicionando login administrativo, usuários, permissões e sincronização real.
